## 搬瓦工是什么？先说清楚

搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 服务商，做了有二十来年了。它的英文名发音和汉语拼音"banwagong"接近，所以国内大家都这么叫。

## 几个容易踩的坑

**坑一：下单挂代理被砍单**。这个发生率挺高的，很多人收到"欺诈订单被取消"的邮件就是因为这个。买之前关掉梯子，注册信息如实填写（拼音就行，不需要完全真实但不要乱填字符）。

**坑二：IP 被封换 IP 要 $8**。搬瓦工更换 IP 地址单次收费 $8，不算便宜。所以机房的选择和用途要想清楚，尽量避免触发这种情况。

**坑三：以为限量版随时有货**。限量版套餐补货后经常几小时内售罄，看到有货直接下，不用纠结配置够不够用——同价位常规套餐配置还不如它。

**坑四：KVM 套餐机房选择比 CN2 GIA-E 少**。KVM 入门套餐只能切 9 个机房，大部分是美国普通线路，没有日本软银和荷兰 9929。如果对线路有要求，直接上 CN2 GIA-E。

**Q：CN2 GIA-E 和 KVM 套餐有什么本质区别？**

**Q：搬瓦工可以部署 AI 应用吗？**
